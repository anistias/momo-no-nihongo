# Momo no Nihongo – APK
Cara paling mudah (tanpa install apa pun):
1. Buat repo baru di GitHub, upload SELURUH isi folder ini (termasuk folder .github).
2. Buka tab **Actions** → "Build APK" → tunggu ±3 menit.
3. Unduh artifact **MomoNihongo-apk** → ekstrak → install `app-release.apk` di HP.

Atau: buka folder ini di Android Studio → Build > Build APK(s).
Ganti isi aplikasi: timpa `app/src/main/assets/index.html`.
